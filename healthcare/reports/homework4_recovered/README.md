# Recovered healthcare results — start here

This saved review contains the recovered financial data, coverage audit, source
evidence, graphs, and regenerated analysis. You can read these files without
running Python or downloading SEC data again.

1. Read [the coverage explanation](READ_ME.md): 49 companies have five matched
   years, 47 have six, and 43 have at least five unflagged equity years.
2. Open [the regenerated analysis report](homework_basis/analysis/20261007T052554249846Z/analysis_report.md).
3. Inspect [the company-by-company audit](company_method_comparison.csv) and
   [the source financials](homework_basis/financials.csv).

These calculations use **year-end balances and later comparative filings**.
Keep them separate from the earlier original-filing/average-balance research
results. Subsector labels remain unclassified; clustering is exploratory.
No AI-generated interpretation is included in this snapshot.

To get this folder on your computer, run `git pull --ff-only origin main` from
your DA401 repository. The files appear under
`healthcare/reports/homework4_recovered/`.

For reproducibility see [the audit guide](../../../docs/Homework4CoverageAudit-guide.md).

For a single command to analyze this data, see [Healthcare workflow](../../WORKFLOW.md).
